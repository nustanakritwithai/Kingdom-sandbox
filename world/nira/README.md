# The Realm of Nira — R0 World Atlas

This branch is reserved for the user-approved The Realm of Nira world data integration.

R0 content is prepared as a separate downloadable package with the original canon map image, 13 regions, 11 factions, 55 locations, 68 indicative routes, 28 resources, a read-only interactive atlas, and validation tests.

The current Kingdom-sandbox game engine and existing save format must remain unchanged until the scenario importer has been validated. Route geometry is schematic and has not passed pixel-level collision review.

See the downloadable Nira R0 package for the validated data and atlas. No NPC agents have been activated by this marker.
